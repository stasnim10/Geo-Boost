Build a web application called GEOboost. The app helps small businesses optimize their content to be cited more often by AI assistants like ChatGPT, Claude, and Perplexity.
The app has two main features:
FEATURE 1 — FREE AUDIT PAGE
A clean landing page with a form that collects:

Business website URL
Business category (e.g. "premium laptop bags", "HVAC services")
Three target queries the user wants to rank for in AI answers

When submitted, the app:

Scrapes the text content from the submitted URL using a fetch request
Sends the scraped content plus the three queries to the Claude API (claude-sonnet-4-20250514)
Claude analyzes the content and returns a JSON object with:

An AI Visibility Score from 0-100
Semantic Density Score from 0-100
Structural Formatting Score from 0-100
Three specific weaknesses found in the current content
Three competitor content patterns the AI prefers over theirs


Display these results in a clean dashboard with score gauges, the three weaknesses listed clearly, and a prominent CTA button: "Optimize My Content — $149/month"

FEATURE 2 — OPTIMIZER PAGE (shown after signup/payment placeholder)
A page where the user pastes their current page content into a text area.
When they click Optimize, the app:

Sends the content plus their target queries to the Claude API
Claude rewrites the content following these specific rules baked into the system prompt:

Add definition-first answers to every likely AI query
Convert vague marketing language into specific factual claims with numbers
Add structured sections with clear headers that match query intent
Bold key entities and specifications
Add a FAQ section at the bottom formatted as direct Q&A
Increase semantic density by adding specific data points


Show a side-by-side comparison: original content on the left, optimized on the right
Highlight every change in the optimized version with a tooltip explaining WHY that change improves AI visibility
Add a one-click copy button for the optimized content

DESIGN: Clean, modern SaaS aesthetic. Dark navy header, white cards, green accent color for scores and CTAs. Mobile responsive. No complex animations.
TECH STACK: Next.js, Tailwind CSS, Claude API for all AI features. Store nothing in a database for now — this is a stateless MVP.
Add a simple email capture before showing audit results — just name and email, no password required."
